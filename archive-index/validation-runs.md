# Validation runs (runner directories)

Back to [ARCHIVE-INDEX.md](../ARCHIVE-INDEX.md). Each entry is a directory under `validation/local/` written by a test-runner subagent: the exact commands, step logs, exit codes, `environment.txt` and usually a `SUMMARY.md` (open that first). Judgements are not here; they are in `ai/implementation/evaluations/*.md` on the working branch. The driver's evidence record for each run is in [evidence-records.md](evidence-records.md).

All runs are local only; none made Cloudflare calls. "rc/" means `ai/implementation/root-causes/`; "eval/" means `ai/implementation/evaluations/`.
