Start with the index, `git show origin/archive/implement-local-cloudflare:ARCHIVE-INDEX.md` (run `git fetch origin archive/implement-local-cloudflare` first). It describes each category in one line and links to a per-category index under `archive-index/` that gives every item's run ID, commit, results and citing documents. Read a file with `git show origin/archive/implement-local-cloudflare:<path>`.
